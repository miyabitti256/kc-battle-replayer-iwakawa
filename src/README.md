# KC Battle Replayer Frontend (SvelteKit)

岩川版七四式戦闘ログ変換ツールのWebフロントエンドです。
詳細はプロジェクトルートの [README.md](../README.md) を参照してください。

## 開発コマンド

```bash
# 開発サーバー起動 (http://localhost:5173)
bun run dev

# テスト実行
bun scripts/testConvert.ts

# Linter & フォーマッターチェック
bun run lint

# SvelteKit 型チェック
bun run check

# プロダクションビルド
bun run build
```
